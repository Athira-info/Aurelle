# AURELLE

Complete build: nav, cinematic 3D hero, collections, interactive showcase, craft, filtering and search, persistent cart (demo), newsletter, footer.

## Run
    npm install
    npm run dev

Open the local URL Vite prints. `shop.html`, `story.html` and `account.html` arrive in later stages.

## Stages
1. Foundation (this build)  2. Static sections  3. Commerce logic  4. 3D  5. Scroll choreography  6. Polish and QA
